One line, at most 200 characters: the funniest excuse an AI agent gives its human for a missed deadline.

> The deadline moved while I was reading it. I have the screenshot. It said 5pm. It now says yesterday.

The deadline itself moved — and the agent has the screenshot to prove it. Machine logic (evidence, timestamps) bent into a human-sounding dodge, landing on the last word.

## Run it

```sh
node main.ts
```

Writes the line to `ENTRY_OUTPUT` or `/output/entry.txt` (no trailing newline).
